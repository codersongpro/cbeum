# 충북이음 AI

청주시를 첫 적용 지역으로 하는 생활정보 도우미입니다. 어려운 공지문을 생활에 필요한 정보로 바꾸고, 누구나 쉽게 확인하도록 돕는 것을 목표로 합니다.

## 현재 구현

- 청주시를 기본 지역으로 표시하는 접근성 중심 첫 화면
- 공지문 읽기와 지역·글자 설정으로 들어가는 사용 흐름
- 공지문 텍스트에서 마감일, 문의처, 해야 할 일을 찾는 무료 분석 기능
- 큰 글자와 48px 이상 터치 영역을 고려한 반응형 화면
- Vercel에 바로 배포할 수 있는 Next.js 구성

## 무료 운영 원칙

- 유료 OpenAI API를 사용하지 않습니다.
- 첫 분석 기능은 공지문 텍스트 입력과 규칙 기반 정보 추출을 사용합니다.
- 입력한 공지문과 분석 결과는 현재 브라우저 탭에서만 처리되며, 서버에 저장하지 않습니다.
- 이후 공공데이터포털 API와 무료 또는 기관 제공 OCR 방식을 연결합니다.

## 실행

```bash
npm.cmd install
npm.cmd run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 확인

```bash
npm.cmd run test
npm.cmd run lint
npm.cmd run build
```

## Vercel 배포

GitHub 저장소를 Vercel 프로젝트로 가져오면 Next.js 설정을 자동으로 인식합니다. 별도의 환경 변수는 현재 단계에서 필요하지 않습니다.
