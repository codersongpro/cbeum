# 무료 공지문 분석 기능 설계

## 목적

충북이음 AI 사용자가 청주시 공지문을 붙여 넣으면 별도 API 비용이나 회원가입 없이 마감일, 문의처, 해야 할 일을 먼저 확인할 수 있게 한다.

## 범위

- 공지문 텍스트 입력과 예시 불러오기
- 브라우저 안에서 실행되는 규칙 기반 정보 추출
- 마감일, 문의처, 해야 할 일, 확인 필요 사항 결과 표시
- 입력 원문을 서버나 데이터베이스에 저장하지 않는 처리

사진과 PDF의 글자 인식, 사용자별 할 일 저장, 공공데이터 연동은 이번 범위에 포함하지 않는다.

## 사용자 흐름

1. 사용자가 첫 화면에서 `공지문 읽기`를 선택한다.
2. 공지문 텍스트를 붙여 넣거나 청주시 예시를 불러온다.
3. `핵심 정보 찾기`를 누른다.
4. 앱이 마감일, 문의처, 행동 문장을 찾는다.
5. 결과 화면에서 찾은 정보와 원문 확인이 필요한 정보를 구분해서 보여 준다.

## 분석 규칙

`lib/notice/analyze.ts`는 순수 함수로 작성한다.

- 마감일: `2026. 9. 30.`, `2026-09-30`, `9월 30일`, `까지`, `마감`과 함께 나온 날짜를 찾는다.
- 문의처: `문의`, `연락처`, `전화`가 포함된 문장과 한국 전화번호 형식을 찾는다.
- 해야 할 일: `신청`, `제출`, `접수`, `방문`, `문의`가 포함된 문장을 최대 3개 찾는다.
- 찾지 못한 정보는 빈 값이 아니라 `원문 확인 필요` 상태로 표시한다.
- 자격 여부, 금액, 주소처럼 규칙으로 확실히 찾을 수 없는 정보는 해석하거나 추측하지 않는다.

## 화면 구성

### 입력 화면: `/analyze`

- 뒤로 가기 링크
- 큰 글자 안내문과 텍스트 입력 영역
- 청주시 예시 불러오기 버튼
- 입력 글자 수 안내
- 48px 이상 높이의 `핵심 정보 찾기` 버튼
- 개인정보와 계좌번호를 입력하지 말라는 안내

### 결과 화면: `/analyze/result`

- 공지문 제목 또는 첫 문장
- 마감일, 문의처, 해야 할 일 순서의 정보 영역
- 원문 확인 필요 안내
- 다시 입력하기 버튼

입력값과 분석 결과는 `sessionStorage`에만 저장한다. 탭을 닫으면 자동으로 사라진다.

## 데이터 구조

```ts
type NoticeAnalysis = {
  title: string;
  deadline: string | null;
  contact: string | null;
  actions: string[];
  warnings: string[];
};
```

## 오류 처리

- 공백만 입력하면 분석하지 않고 입력 안내를 표시한다.
- 브라우저 저장 기능을 사용할 수 없으면 결과 화면 대신 입력 화면에 오류를 표시한다.
- 분석에서 정보를 찾지 못해도 오류로 처리하지 않으며, 원문 확인 안내를 제공한다.

## 검증

- 날짜, 전화번호, 행동 문장 추출을 단위 테스트로 확인한다.
- 빈 입력을 거부하는 동작을 테스트한다.
- 결과 화면이 추출한 정보와 원문 확인 안내를 표시하는지 테스트한다.
- 린트와 프로덕션 빌드를 실행한다.
